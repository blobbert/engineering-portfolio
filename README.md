# Jiajie's Engineering Portfolio

A personal website showcasing engineering projects, interests, and skills.

[Visit the portfolio](https://blobbert.github.io/engineering-portfolio/)

## What's on the website

- **Projects:** A gallery of project cards with summaries, cover images, and tags. Visitors can filter projects by tag and open individual write-ups.
- **Project pages:** Detailed write-ups with support for images, galleries, code examples, and downloadable resources.
- **About me:** An introduction, engineering interests, and skills and tools, with space for experience and contact links as they are added.
- **Appearance:** Light and dark modes with a saved preference, responsive layouts, and subtle animations that respect reduced-motion settings.

The site currently includes example projects and placeholder biography and skills text while the portfolio is being filled in.

Built with Astro, TypeScript, Markdown, and CSS, and hosted on GitHub Pages.
